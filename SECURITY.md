# Security Policy

## Supported versions

Only the latest release on PyPI is actively maintained.

| Version | Supported |
|---------|-----------|
| 0.3.x   | Yes       |
| < 0.3   | No        |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

### Preferred: GitHub Security Advisory (private)

Open a private advisory at:
https://github.com/hemanpadvas2002/query-oracle/security/advisories/new

GitHub keeps the report confidential until a fix is released. This is the
fastest path to a coordinated disclosure.

### Fallback: email

If you cannot use GitHub, email **tailung.hp@gmail.com** with the subject
line `[query-oracle] Security vulnerability`. Include:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept (kept confidential)
- Any suggested fix, if you have one

### What to expect

- Acknowledgement within 72 hours
- A patched release as quickly as the severity warrants
- Credit in the release notes if you wish to be named

Thank you for helping keep query-oracle secure.
